# Чек-лист готовности игры Arcomage

Игра считается готовой, когда реализован следующий функционал:

### 1. Ядро игры (Core Mechanics)
- [ ] **Машина состояний (FSM):** Реализация всех состояний в `match_manager.gd`: `START_MATCH`, `PLAYER_TURN`, `AI_TURN`, `PROCESS_CARD`, `CHECK_WIN`, `END_MATCH`.
- [ ] **Интерпретатор эффектов:** Универсальная система обработки эффектов карт (`damage`, `build`, `discard`, `draw` и др.) согласно `data/resources/card_data.gd`.
- [x] **Игровая логика:** Корректная обработка урона (учет стены перед башней), автоматический прирост ресурсов на основе генераторов (`quarry`, `magic`, `dungeon`) и проверка условий победы.

### 2. Контент и Данные
- [ ] **Библиотека карт:** Создание всех запланированных карт (минимум 30–60 уникальных) в виде файлов `.tres` через `Resource`.
- [ ] **Система артефактов:** Реализация логики `artifact_data.gd` и их влияние на геймплей через систему событий `game_events.gd`.

### 3. Искусственный интеллект (AI)
- [ ] **Весовая система выбора:** Реализация алгоритма принятия решений ИИ, учитывающего состояние HP игрока/ИИ, текущие ресурсы и состояние стен.
- [ ] **Обработка патовых ситуаций:** Автоматический сброс случайной карты, если ни одна из имеющихся карт не может быть сыграна.

### 4. Интерфейс и Визуализация (UI/UX)
- [x] **Боевой экран:** Динамическое обновление всех показателей (HP, ресурсы) через `battle_screen.gd`.
- [x] **Анимации:** Использование `Tween` для всех значимых событий: перемещение карт, эффекты боя, изменение цифр ресурсов.
- [ ] **Меню:** Реализация главного меню, экранов завершения боя и настроек.

### 5. Рогалик-составляющая (Progression)
- [ ] **Карта мира:** Генератор путей с узлами (бой, элита, магазин, событие) и логика перемещения по ним.
- [ ] **Мета-прогрессия:** Система сохранения (локальные файлы + `ysdk.player.setData`), древо навыков, экономика внутри забега.

### 6. Интеграция Яндекс Игр (SDK)
- [ ] **Монетизация:** Полная интеграция Rewarded Video (для бонусов) и Interstitial рекламы.
- [ ] **Техническая полировка:** Оптимизация размера проекта, корректная пауза при потере фокуса браузером, адаптивность под мобильные устройства.
