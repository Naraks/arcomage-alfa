# Список карт (сбалансированный набор v2)

60 карт — по 20 на каждый тип ресурса, 8 обычных / 7 необычных / 5 редких на тип. Заменяет предыдущую версию
этого файла. Принципы баланса и ролевой состав — в `game_design_doc.md`, разделы 5 и (для процесса ревью) в
истории чата, где набор согласовывался по юнитам. Точные числа — стартовая гипотеза, финальная калибровка
через симулятор ИИ-против-ИИ (`dev_plan_tickets.md`, ARC-023).

**Заметка по реализации:** карты «порчи генераторов» (Порча Карьера/Подземелья, Разрушение Основ, Дикие
гончие) используют уже существующие эффекты `mod_quarry`/`mod_magic`/`mod_dungeon` с отрицательным `value` и
`target: "enemy"` — новый тип эффекта в интерпретаторе не нужен. Единственное требуемое изменение —
ограничить генератор снизу нулём (`max(0, quarry - value)`), иначе он теоретически может уйти в минус.
