# Список карт (сбалансированный набор v2)

**Этот файл — единственный источник истины по картам (ARC-024).** Другие доки (`game_design_doc.md` и т.д.)
не дублируют точные числа/список — только ссылаются сюда; если где-то встретится расхождение, прав этот файл,
остальное надо поправить.

68 карт — 22 Кирпичи / 23 Гемы / 23 Звери (ARC-084: 66→68 — убраны 4 точных дубликата/доминируемых карты
(«Малая стена», «Стена 1», «Малый взрыв», «Медведь»), добавлены 6 новых карт верхнего края `cost`;
до этого — расширение набора ARC-020 с исходных 60 карт по 20 на тип).
Рарность внутри каждого типа: Кирпичи 8 обычных/7 необычных/7 редких, Гемы 9/7/7, Звери 10/6/7. Принципы
баланса и ролевой состав — в `game_design_doc.md`, раздел 5 (только качественное описание, без точных
чисел). Точные числа — стартовая гипотеза, калибровка через симулятор ИИ-против-ИИ (GitHub Issues,
ARC-023, ARC-084).

**Заметка по реализации:** карты «порчи генераторов» (Порча Карьера/Подземелья, Разрушение Основ, Дикие
гончие) используют уже существующие эффекты `mod_quarry`/`mod_magic`/`mod_dungeon` с отрицательным `value` и
`target: "enemy"` — новый тип эффекта в интерпретаторе не нужен. Единственное требуемое изменение —
ограничить генератор снизу нулём (`max(0, quarry - value)`), иначе он теоретически может уйти в минус.

кража/иссушение ресурсов врага, порча генераторов врага). Строительных карт мало (только щиты), урона через
