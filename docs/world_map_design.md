# Дизайн карты мира (ARC-009)

Этот документ фиксирует финальную схему карты мира — количество этажей, состав каждого этажа и
распределение типов узлов — как основу для генератора путей (ARC-010) и остальных тикетов Эпика
карты (ARC-011…ARC-015). Общий контекст и обоснование см. в `game_design_doc.md`, раздел 7; здесь —
конкретные числа и правила, достаточные для реализации без дополнительных дизайн-решений.

## 1. Типы узлов

`MapNodeData.NodeType` (`data/resources/map_node_data.gd`):

```
enum NodeType { BATTLE, ELITE_BATTLE, SHOP, REST, EVENT, BOSS }
```

| Тип | Описание | Реализующий тикет |
| :--- | :--- | :--- |
| `BATTLE` | Стандартный бой против случайного архетипа ИИ | Готово |
| `ELITE_BATTLE` | Усиленный бой, ценная гарантированная награда | ARC-013 |
| `SHOP` | Покупка/удаление карт за золото забега | ARC-012 |
| `REST` | Выбор одного из двух постоянных на забег усилений | ARC-014 (не заведён отдельно, см. роадмап) |
| `EVENT` | Текстовое событие с 2-3 вариантами и последствиями | ARC-013 (события) |
| `BOSS` | Финальный узел карты, гарантированная награда-артефакт | ARC-015 (награда), генератор — ниже |

## 2. Количество этажей

* Карта — **12–15 этажей**, включая финальный этаж босса.
* Значение хранится в `WorldMapData.floor_count` и выбирается генератором (ARC-010) один раз при
  создании забега, в диапазоне `[12, 15]` включительно.
* Последний этаж (`floor_count - 1`, при нумерации с 0) всегда состоит из **ровно одного узла**
  типа `BOSS`.

## 3. Узлы на этаж

* Каждый обычный этаж (все, кроме последнего) содержит **2–4 узла**.
* Число узлов на этаже выбирается генератором случайно (в диапазоне `[2, 4]`), детерминированно по
  `WorldMapData.seed`.
* Пути ветвятся и иногда сходятся к следующему этажу (по образцу *Slay the Spire*): узел этажа `i`
  соединяется с 1–2 узлами этажа `i+1`; у каждого узла этажа `i+1` есть хотя бы одно входящее
  соединение (сирот без входящих рёбер быть не должно). Пересечения рёбер "в обратную сторону"
  (когда ребро идёт от узла справа к узлу слева при более раннем left-to-right упорядочивании)
  запрещены — это требование уже зафиксировано в описании ARC-010.
* Финальный этаж перед боссом: все его узлы соединяются с единственным узлом `BOSS` — гарантия
  того, что путь до босса существует из любой точки карты (критерий ARC-010).

## 4. Распределение типов узлов

Распределение смещено в сторону обычных боёв — это боевая игра, и полностью избежать сражений
нельзя. Базовые веса для обычного этажа (не первого и не предпоследнего, см. исключения ниже):

| Тип | Вес |
| :--- | ---: |
| `BATTLE` | 45% |
| `ELITE_BATTLE` | 15% |
| `SHOP` | 10% |
| `REST` | 15% |
| `EVENT` | 15% |

### Исключения по этажам

* **Первый этаж (индекс 0):** только `BATTLE` и `EVENT` — игрок ещё не готов к элите/тратам золота,
  которого пока нет. Веса: `BATTLE` 70%, `EVENT` 30%.
* **Первые два этажа (индексы 0–1):** `ELITE_BATTLE` исключён полностью — риск усиленного боя не
  должен встречать игрока в самом начале забега.
* **Предпоследний этаж (последний перед `BOSS`):** `SHOP` исключён (не даём тратить золото прямо
  перед боссом, когда лучше подготовиться к бою), и минимум один узел этажа обязан быть `REST` —
  гарантированная возможность подлечиться/усилиться перед боссом, аналогично Slay the Spire.
* **Каждый обычный этаж обязан содержать хотя бы один узел `BATTLE` или `ELITE_BATTLE`.** Полностью
  "мирный" этаж (только `SHOP`/`REST`/`EVENT`) запрещён — иначе забег превращается в этаж без боя,
  что противоречит жанру.

Генератор (ARC-010) применяет веса выше как основу, затем перепроверяет два инварианта из
последнего пункта (наличие боя, наличие `REST` на предпоследнем этаже) и при необходимости
принудительно заменяет один случайный узел этажа на нужный тип.

## 5. Детерминизм

* `WorldMapData.seed` — сид генерации, задаётся при старте забега (например, `randi()` при обычном
  забеге или фиксированное значение для "дневного забега" в будущем).
* Генератор обязан быть чистой функцией от `seed`: одинаковый `seed` → одинаковый граф (граф,
  распределение типов, `floor_count`). Это требование напрямую используется юнит-тестом ARC-010
  ("сгенерировать 100 карт и проверить валидность связности").

## 6. Изменения данных (эта итерация, ARC-009)

* `data/resources/map_node_data.gd`: `NodeType` расширен до
  `BATTLE, ELITE_BATTLE, SHOP, REST, EVENT, BOSS`.
* `data/resources/world_map_data.gd`: добавлены поля `floor_count: int` и `seed: int`.

Сам генератор графа (наполнение `map_nodes`/`connected_nodes` по правилам выше) — предмет ARC-010,
не этого тикета; текущий `ui/main_menu.gd._on_campaign_pressed()` продолжает создавать
заглушечную карту из 2 узлов до реализации ARC-010.
