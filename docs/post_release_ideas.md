# «Башни магов: Дуэль» — идеи развития после релиза

Список идей для развития игры после релиза. Это не бэклог задач (см. GitHub Issues) и не обязательства —
черновой список направлений, из которых позже можно будет сформировать тикеты, когда до них дойдёт очередь.

---

## 1. Дополнительные кампании

Новые кампании поверх стартовой: другой сеттинг/тема, новый набор врагов на карте мира, новые карты и артефакты,
специфичные для кампании (не пересекаются с базовым пулом или пересекаются частично). Потенциально — свои
модификаторы забега (мутаторы) и свой финальный босс.

---

## 2. Тематические временные кампании (ивенты)

Ограниченные по времени кампании под праздники/события (например, новогодняя) — отдельная тема оформления,
свои карты/артефакты/враги на время ивента, потом кампания скрывается до следующего раза. Хорошо сочетается с
идеей №1 (переиспользует тот же механизм доп. кампаний, но с датами активности и сезонным оформлением).

---

## 3. Карты с длительными эффектами (дебаффы на несколько ходов)

Карты, накладывающие эффект на несколько ходов, а не разово: например «Заморозка» — стена противника заблокирована
на 3 хода, он не может её строить; «Чума» — на несколько ходов нет прироста зверей. Плюс карты, снимающие такие
эффекты (аналог «очищения»/антидота) — дают противнику (или себе) способ вернуть контроль. Потребует счётчика
длительности на PlayerData и обработки в начале хода (тикает вместе с существующим `start_turn()`).

---

## 4. Специализации магов

Хаос-маг (использует заклинания других магов; шанс что заклинание изменится на другое)
Маг стихий (стихии, элементали)
Друид
Имперский маг (рыцари, лучники (войска империи))
Некромант
